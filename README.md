## 使用说明

- 所有 HTML 文件均为自包含页面（内嵌样式与脚本），无需联网即可本地浏览。
- 点击上方链接可在 GitHub 上直接预览渲染效果；如需交互训练，建议 clone 仓库后用浏览器打开。
- 推荐阅读顺序：先过 `theory-180-300` 与各专项巩固基础，再按 `thesis/01 → 20` 顺序练习论文。
